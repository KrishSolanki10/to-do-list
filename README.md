<h2>🧠 About the Project</h2>

<p>
Simple To-Do List is a lightweight task management application that allows users to quickly add, view, and manage daily tasks without unnecessary complexity.
</p>

<p>
This project focuses on building clean logic, intuitive UI flow, and practical usability while strengthening frontend fundamentals and consistency in coding practice.
</p>

<hr>

<h2>✨ Features</h2>

<ul>
  <li>➕ Add tasks instantly</li>
  <li>📋 View all pending tasks clearly</li>
  <li>✅ Mark tasks as completed</li>
  <li>🗑️ Remove tasks when done</li>
  <li>🎨 Minimal & aesthetic interface</li>
  <li>📱 Responsive design</li>
</ul>
